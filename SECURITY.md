# Security Policy

## Supported versions

The `main` branch and the latest `v0.3.x` release.

## Report a vulnerability

Please **do not** open a public GitHub issue for a security bug.

Email **nikaquantcom-byte** via GitHub, or open a [private security advisory](https://github.com/NikaQuant/hermes-companion/security/advisories/new) on this repository.

Include:

- Companion version (`vX.Y.Z · <build>` in the app header)
- What you did, what happened, what you expected
- Whether you have a working exploit (describe, don't attach malware)

We'll acknowledge within a few days and fix before any disclosure.

Threat model and controls: [`docs/SECURITY.md`](docs/SECURITY.md), [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md).
